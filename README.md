# Wsley

Wsley 是面向 Ubuntu 的开发环境管理器，覆盖系统工具、终端配置、语言运行时、开发应用及 Codex skills，提供从环境初始化到日常维护的统一命令行入口。

项目基于 Shell 脚本实现，以模块为单位组织软件、配置与运行依赖，支持独立安装、分组批量操作、软件升级及本地状态查询。各模块负责配套环境的安装与配置，组件范围、操作说明和环境要求通过命令行统一展示。

## 快速开始

```bash
curl -fsSL https://raw.githubusercontent.com/oryth-ai/wsley/main/wsley/install.sh | bash
```

## 命令说明

| 命令                            | 说明                                 |
| ------------------------------- | ------------------------------------ |
| `wsley list [模块或分组]...`    | 查看分组与模块，或指定模块的详细说明 |
| `wsley install <模块或分组>...` | 安装所选模块或分组                   |
| `wsley upgrade <模块或分组>...` | 升级所选模块或分组                   |
| `wsley status <模块或分组>...`  | 查询所选模块或分组的本地状态         |
| `wsley update`                  | 更新 Wsley 自身                      |
| `wsley help`                    | 查看命令帮助                         |

可同时传入多个模块名或分组名；安装、升级和状态查询按参数顺序展开，每个模块只执行一次。
