# 资源与动效

## SVG

先确定准确文字、信息层级、坐标和留白，再制作形状、连线与必要装饰。系统字体的字宽可能变化，核对中英文换行与裁切，不把文字直接画进不可编辑的生成图。

图表依据真实节点、关系和范围绘制，现有图标与品牌资产保持正确比例和授权。资源路径在实际渲染器中验证，不能依赖只有本机才能找到的文件。

需要可编辑 draw.io 产物时采用 [next-ai-drawio](../../next-ai-drawio/SKILL.md)，需要独立交互说明页时采用 [archify](../../archify/SKILL.md)。README 静态资源按当前交付格式导出，不强制引入其他产物。

## 混合合成

先确定主体与排版，按实际授权获取或生成素材。生成提示描述主体、构图、材质与光线，准确标题、命令和数据由 SVG 或其他确定排版层提供。

需要透明背景时保留主体透明 PNG，在明暗背景检查边缘、角落与杂色。合成后按实际发布尺寸查看，避免将不稳定的相对图片引用作为最终 SVG 交付。

通常保留 SVG 排版、图像源层及最终 PNG/WebP。资源清单、导出位置和交付范围依据项目约定，不为套用目录模板新增无用文件。

## GIF

只有用户选择运动且运动能解释项目机制时才制作。设计进入、稳定停留、退出与循环衔接，正文、操作与项目价值在静止帧也可理解，不用闪烁、快速平移或持续大范围缩放吸引注意。

保留 SVG 静态源与清晰的稳定帧。使用已安装的浏览器录制或渲染所需帧，并通过 FFmpeg 等现有工具生成合适尺寸、帧率与调色板的 GIF；命令参数根据实际资源选择，不依赖不存在的技能内脚本。

按正常速度查看完整循环及关键帧，检查文字、时长、背景、体积和循环边界。GitHub 中不依赖 SVG 内嵌动画，嵌入 GIF 与更新 README 分别需要相应任务范围。
