# Web 实现检查

按页面实际包含的内容选择检查项。设计选择需有任务或项目依据，自动工具给出的提示仍要核对真实影响。

## 结构与操作

- 导航使用可跟随的链接，动作使用按钮，图标操作具有可访问名称
- 保留新标签页、复制链接、浏览器返回与键盘等原生行为，不让嵌套交互互相触发
- 地址表达需要分享和恢复的筛选、分页、选中对象与视图；本地草稿按产品契约保存
- 弹窗打开、关闭与路由变化正确管理焦点，固定导航不遮挡目标内容
- 重复提交、处理中离开、超时与结果未知具有明确反馈和恢复身份

## 表单与状态

- 字段有持久标签，类型、`inputmode`、`autocomplete` 与真实输入匹配，允许合法粘贴和自动填充
- 输入限制在提交前可理解，错误关联到具体字段，失败保留已输入内容
- 支持适用的键盘提交，按钮禁用与等待状态不让操作或结果永久失去入口
- 空结果、读取失败、无权限、部分成功与真正完成分别表达，不用一个通用空页面覆盖
- 离开未保存内容、危险操作与不可逆后果按产品规则处理，确认不能替代服务端授权

## 排版与适配

- 宽窄视口、缩放、长标题、长链接、无空格标识和多语言文本不会裁切必要信息
- 使用内容驱动的尺寸、合理换行、逻辑方向属性及移动设备安全区域，避免只按固定截图定位
- 层级、数字单位、时间范围、表格对齐和金额精度保持可读，图表保留精确值与真实基线
- 明暗主题下核对背景、输入、选中、禁用、悬浮和焦点状态，尊重系统高对比度与减少动态效果偏好
- 交互目标具有适当尺寸和间距，悬浮提示中的必要信息也能通过键盘和触摸获得

## 资源与性能

- 图片声明尺寸以减少布局偏移，按展示尺寸提供资源；首屏关键图与屏外图采用适当加载优先级
- 字体与图标资源按实际使用加载，避免无限预加载、远程依赖失效和大量字体阻塞内容
- 大列表、复杂图表和屏外内容按测量结果控制成本，不能为优化移除语义、搜索或键盘可达性
- 动画优先使用适合合成的属性，避免强制同步布局；装饰动效不阻塞操作或隐瞒状态变化
- 事件监听正确解除，页面切换结束失效请求与资源；缓存按身份和范围隔离

## 验证

从真实入口覆盖主要操作、错误和恢复，检查键盘与实际视口。记录真实设备、浏览器、数据和限制，不用截图证明交互成功，也不以实现了某个性能技巧代替前后测量。
