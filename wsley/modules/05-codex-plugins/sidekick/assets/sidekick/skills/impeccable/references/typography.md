# 排版

## 字体性格与层级

让字体承担内容角色与产品语气。展示标题可以通过字形、比例、宽度、字重和构图成为视觉主体；工作与阅读界面通过稳定层级、良好字面和精确节奏形成品质。沿用已经确定的品牌，新方向按目标选择，不从固定字体名单或衬线、无衬线二选一反推产品。

为标题、正文、标签、操作、数据和代码确定必要角色。通过尺寸、字重、空间和色调的共同变化建立清楚的主次，避免相邻角色只有难以察觉的差别，或每段文字都同样粗大。字族数量服从实际分工，一套优秀字体也能形成丰富层级。语义标题表达文档结构，视觉尺寸由上下文确定，两者分别核对。

## 行长与构图

用真实文字在目标尺寸阅读，联合调整字号、容器、行高和字距。大标题的换行参与构图，正文的行长与段落节奏支持连续阅读；小标签、密集数据和窄屏各自判断。行长建议可作为起点，不能将某个字符数、字号或行高作为中文、拉丁文和所有表格的合格线。

标题可在支持范围内使用 `text-wrap: balance`，正文可按需要采用 `pretty`；浏览器回退仍应可读。手工换行用于确有表达作用的位置，并在不同宽度重新核对。大幅压缩字距、轻字重与低对比组合不能代替精致排版，也不通过强制抗锯齿掩盖字体选择问题。

段落、标题和分组间距形成阅读节奏。光学对齐与数学对齐分别检查，图标、标点和混排可能需要局部调整；不使用补空格对齐数值或统一固定高度掩盖内容差异。

## 资源与实际字形

从字体文件、`@font-face`、加载请求与浏览器渲染确认字族、字重、样式和字符覆盖。CSS 声明不代表对应字形实际使用了该字体；中英文、数字、符号和 emoji 可能分别回退。先解决缺失资源、错误映射和字形回退，再微调间距。

变量字体先核对真实轴与范围。优先使用 `font-weight`、`font-stretch`、`font-style` 和 `font-optical-sizing` 等高层属性；确需控制特有轴时才直接设置 `font-variation-settings`，避免覆盖已有轴值。[字体轴说明](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/font-variation-settings)

只加载实际使用且许可适用的资源、字重和字形范围。按项目环境选择本地或远程加载及回退策略，检查字体交换造成的重排、缺字与不可见文字；不能因字体有表现力就忽略加载成本，也不为节省准备步骤默默换成不相符的字体。

## 溢出、数据与语言

长 URL、无空格标识和用户输入需要明确的换行或滚动策略。先检查容器收缩，再选择 `overflow-wrap`、滚动或截断，避免全局 `word-break: break-all`。确需截断的预览提供必要全文入口，不能只依赖 `title` 或 hover；唯一的任务依据不可被裁掉。

金额、计时、计数和比较列保持契约要求的精度、单位与对齐。字体支持时，`font-variant-numeric: tabular-nums` 可稳定动态数值和列，连续文字按需要采用比例数字。数字的视觉强调仍要表达当前范围、时间和状态。

保留真实 `lang`、方向和本地化规则。用户名称、编号和双向文字在合适边界隔离，方向变化不等于镜像所有图标与数据。大小写、标点、引号和字距按实际语言判断，不把英文标题规则用于全部 locale。

## 验证

在真实尺寸与缩略画面中分别检查阅读和层级，确认字体性格仍属于选定方向。覆盖加载前后、长短标题、多行操作、混排、缩放和必要的缺字场景，复用 [组件状态与压力验证](component-states.md)。移动端输入出现意外缩放时复现原因，调整可读字号与布局，保留浏览器缩放和用户字体设置。
