# Internationalization

按产品支持的语言、地区和现有本地化架构实现完整的界面表达。语言列表、资源格式、路由策略和翻译质量来自项目与用户要求，不预设中英双语或指定框架。

## 范围与资源

读取现有 provider、路由、翻译资源、格式化工具和项目约定，确定当前目标是建立基础、补齐覆盖、修复切换还是审计。已运行的本地化体系优先复用；只有当前任务要求且确有必要时才引入库或调整结构。

沿界面状态盘点可见文字、标题、菜单、输入提示、错误、通知及辅助技术标签。产品拥有的界面内容需要本地化，用户输入、原始业务数据、稳定协议字段和诊断日志按各自约定处理。

## 文案与键

使用稳定语义键和项目已有命名空间，关联语言中的键、插值变量与复数分支保持契约一致。避免按原文机械生成不稳定键，也不为统一外观随意重命名已有资源。

完整句子保留为完整翻译单元，通过插值表达变量，不把多个词片段拼成自然语言句子。保留实际消息语法中的占位符、转义、富文本标记和复数规则；不同语言不能机械套用同一组词尾。

数字、货币、日期、时区、相对时间、列表和排序采用项目已有或 `Intl` 等适用格式化能力。金额精度、存储单位和时区事实由业务契约决定，格式化不改变数据含义。

## 切换与错误

核对语言检测、首屏渲染、URL、用户选择持久化和资源加载的先后关系，避免 hydration 不一致、切换闪烁及缓存串语言。切换保留当前对象、合法路由参数、用户输入和未完成状态。

稳定错误类别映射到产品语言中的消息，未知错误使用真实且可操作的通用说明；不直接展示内部异常，也不能把所有失败翻译成同一种业务拒绝。文案设计使用 [ux-copy](../ux-copy/SKILL.md)。

目标范围包含 RTL 时核对方向、逻辑 CSS、数字、图标和混排文本。公开多语言页面需要 SEO 时衔接 [seo-audit](../seo-audit/SKILL.md)，不因界面翻译自动新增语言路由或公开页面。

## 验证与交付

使用项目已有检查器或临时命令核对资源语法、真实引用、键覆盖、占位符和复数；静态搜索无法识别的动态键单独追踪。缺失翻译、合法的语言差异与不再使用的键分别判断，不靠复制源语言内容伪造完成。

实际查看目标语言下的长短文本、日期、数字、错误和关键状态，验证切换、刷新、深链接与回退策略。覆盖目标范围内的桌面、窄屏和辅助技术标签，说明未取得真实语言校对的部分。

修改遵循 [disciplined-dev](../disciplined-dev/SKILL.md)，同步界面、资源和必要验证。交付实际覆盖的语言、状态与限制，不把 JSON 解析通过当作翻译质量或完整行为证明。
