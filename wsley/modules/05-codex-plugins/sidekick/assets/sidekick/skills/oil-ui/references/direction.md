# 方向与对比

## 产品依据

先确定品类、目标人群、主任务、首屏需要传达的事实和期望动作。参考同类优秀产品时拆解信息顺序、构图和控件语法，说明可借鉴的机制，不复制其业务主张、品牌或资产。

把“高级”“轻盈”“科技”等词转为具体决定，例如文字密度、对比、色彩范围、图片角色、空间节奏和操作反馈。方向的辨识度来自产品，不从固定字体、渐变、网格或卡片模板推导。

## 方向说明

每个候选写清适用任务、主要构图、文字层级、色彩、素材与关键交互，说明与其他候选的实质差异。仅换主题色不构成不同方向。

保留用户已经确认的品牌、参考和结构。不同方案只改变尚未确定的设计维度，不用虚构用户研究证明审美选择；缺少证据时说明设计假设。

## 可运行对比

用户需要看实际画面时，以相同内容和数据制作适当数量的代表页面或首屏，候选有各自清楚的骨架。并排对比以构图和阅读效果为目的，候选阶段只实现辨别方向所需的内容。

用可运行页面、稳定地址或实际截图呈现比较，标明选择与理由。交付 HTML、设计说明或原型根据用户请求确定，不能在只要文字建议时默认新增页面。

方向选定后集中到选定方案，保持字体、色彩、控件和素材语法一致。用户要求比较布局时只改变相应维度，不重新打开已经完成的品牌与风格决定。

## 参考还原与组件

参考截图先记录视口、容器、网格、字体与图片裁切，区分要精确还原的结构和允许调整的内容。比较在相同视口进行，不用整体缩放掩盖字体、密度和布局差异。

单个组件的深化围绕主要操作和状态完成，在实际相邻内容中检验，不为突出组件建立与产品不相容的视觉系统。
