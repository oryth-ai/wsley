# 视觉与交互

## 内容与空间

每个区域有明确的信息或操作职责，层级通过尺寸、字重、留白、颜色与对齐共同表达。表格、字段、卡片、时间线和图表根据内容关系选择，不用更换容器的数量衡量设计质量。

标题、正文、数字与标签在实际阅读尺寸清楚可辨。检查中文多行标题、长名称、混排、数值单位和窄屏换行；出现裁切或重叠时修正内容与布局，不靠大量小字容纳。

减法删除重复、无用装饰和不能帮助决策的解释，保留对象名称、判断依据、状态、主要动作与恢复方式。原型的制作说明放在交付中，产品本来需要告知的隐私和存储事实仍在界面清楚表达。

## 色彩、图像与材质

色彩来自品牌、内容或主素材，强调色承担明确作用。核对主题、状态与对比，不能只通过颜色传达错误、选中和业务结果。圆角、线条、阴影和表面保持同一应用内语法。

优先使用真实产品截图、输出、品牌或已授权素材。图像承担信息、情绪或操作对象的明确职责，避免空泛的技术装饰；生成内容、贴图、角色和科学素材保留其来源与适用限制。

生成图像时描述主体、构图、光线、材质和需要保留的留白，准确文字与数据由可控排版完成。图片放入真实页面后再判断裁切、焦点、色彩和分辨率，不能只看孤立素材。

实时 3D、视频与复杂材质具有性能、加载和交互成本。确有沟通收益时才采用，提供适当的静态表达和用户控制，不因素材能力扩大为接入新服务。

## 动效与游玩

动效解释状态、空间关系或操作反馈，节奏与幅度服从任务。首屏、滚动叙事和页面转场按内容组织，不规定每个界面必须包含固定数量的动画。

滑动驱动的叙事具有清楚的内容段落和连续阅读路径，窄屏、减少动态效果和无脚本场景保留必要信息。成熟库可以复用，但引入与否依据项目工具链和实际收益。

游戏、计时、养成或强反馈控件关注动作的节奏、结果可读性和实际状态。随机、次数、余额和存档按产品契约验证，不能用视觉反馈伪装未成立的奖励或持久化结果。
