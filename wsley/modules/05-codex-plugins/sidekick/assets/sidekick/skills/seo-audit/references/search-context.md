# 语言与搜索数据

## 国际页面

确认产品真正支持的地区与语言，主内容、标题和描述具有相应语言版本。只翻译导航而正文相同不能冒充完整语言覆盖，不为增加页面数量自动生成大量低价值内容。

hreflang 核对语言和地区代码、自引用、互相返回的关系、有效目标与 canonical 的一致性。HTML、HTTP 头和 sitemap 可以表达这些关系，采用何种方式按项目结构选择；不要因一个错误关联推断全部语言页面失效。

根据实际选择设置适当的默认入口或 `x-default`，它不是所有场景的强制项。语言地址、跳转、用户选择与爬虫可达性共同核对，不能仅依赖浏览器语言或 IP 猜测隐藏内容。

具体搜索系统行为以 [本地化版本说明](https://developers.google.com/search/docs/specialty/international/localized-versions) 为依据，避免把平台建议写成未经验证的绝对规则。

## 已有页面与变化

按页面、查询、设备、地区和时间窗口拆分展示、点击、CTR 和排名数据。识别季节性、迁移、产品变化、索引变化与内容改写，不从单次升降直接推断原因。

页面已有展示但点击低时核对搜索意图、标题、呈现及竞争结果；排名接近目标时核对内容、内部链接和真实差异。改写标题保留主主题和事实，不把固定字符数当作成功标准。

实验记录基线、变更、观察窗口和并行因素，明确相关性与因果证据的区别。分析数据缺失、权限不足和时间尚短时限定结论，不生成虚构增长报告。

## 本地业务

核对实际门店、服务区域、名称、地址、电话、营业时间与公开资料的一致性。地区页面需要真实服务信息，不能用替换地名批量制造相同内容。

商家资料、分类、评价和地图呈现使用实际账户与授权。提出资料修正、执行外部提交和征求评价是不同操作，不能通过伪造评价或地址补齐清单。
