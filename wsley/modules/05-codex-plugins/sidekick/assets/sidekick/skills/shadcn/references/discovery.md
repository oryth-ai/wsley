# 官网与发现

## 入口选择

按任务使用 [shadcn/ui 官网](https://ui.shadcn.com/)，不把首页演示、组件用法与可安装区块当成同一种资源。

| 入口 | 适合解决的问题 | 需要取得的依据 |
| --- | --- | --- |
| [首页](https://ui.shadcn.com/) | 观察整体风格、组件组合与布局关系 | 实际画面与交互；需要复用时再追踪 Get Code 或对应官方源码 |
| [Components](https://ui.shadcn.com/docs/components) | 选择单个组件、变体与组合 API | 匹配基础库的文档、预览、View Code、安装及必要手动源码 |
| [Blocks](https://ui.shadcn.com/blocks) | 选择登录、侧栏、仪表盘等多文件组合 | Preview、Code、文件树、区块标识及安装命令 |
| [Charts](https://ui.shadcn.com/charts) | 选择适合数据关系的图表与交互 | 图表预览、代码、数据及图例配置，核对实际依赖与数据契约 |
| [Directory](https://ui.shadcn.com/docs/directory) | 官方示例不能满足且任务需要其他 registry | 实际来源、许可、依赖、认证和维护情况 |

用户已指定官网、区块或 registry 时沿该来源查找。否则先使用项目已配置来源及适合的官方实现，不为普通组件强制询问 registry，也不默认扩展到第三方。官方目录收录不代替对具体第三方代码与许可的核对。

## 观察与读取

视觉与交互通过 [agent-browser](../../agent-browser/SKILL.md) 实际查看。需要比较布局、密度、状态和响应式行为时使用对应预览；读取文档与代码可用现有抓取工具或浏览器的文档读取能力，按需取得相关章节，不加载全站文档。

文档、示例与 API 地址可从匹配基础库的官网导航、CLI 的 `docs <component>` 或 `info` 返回的链接取得。CLI 提供地址后仍要读取实际内容，查询失败也不代表官网内容不存在；沿已确认的官方入口取得可访问资料，不把链接本身当作已经查阅。确认网页显示的基础库、示例变体、主题和视口，默认入口可能跳转到与项目不同的实现。

使用 View Code 或区块 Code 时检查折叠内容和文件树，取得需要的完整源码。区块入口引用的子组件、hooks、数据及样式同样属于集成范围；提取 DOM 或截图只得到页面表现，不能作为完整可维护源码。

## 选择与取码

先确认示例解决的任务与适配代价，再取得对应实现。现有方向明确时沿其筛选，不能因官网示例的配色、字体或排版更新而重新打开已确认选择；数据图表按真实比较关系选择，不为匹配截图虚构数值。

官方 registry 中的组件与区块优先通过 [项目与 CLI](integration.md) 解析，以采用项目配置下的路径、样式和依赖。官网代码支持阅读与核对，不能只复制一段演示 JSX 后猜测其余 API；需要手动集成或版本定位时读取官方对应源码并保留必要归属。

记录任务确实需要的示例地址或区块标识及采用的机制，区分视觉参考与实际代码来源，不默认创建研究报告或项目说明文件。来源不可访问时说明缺少的是画面、文档还是源码，不能把未查看的示例写成验证证据。
